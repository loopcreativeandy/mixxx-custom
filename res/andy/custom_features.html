Andy's Mixxx — custom features

Everything this build adds on top of stock Mixxx 2.6, grouped by area, with where to find it and how to use it. The grey tag (CP112) is the checkpoint it was built in, so it can be looked up in the build log. Use the search box above to find a word on this page (Enter = next hit).

Keyboard shortcuts

KeyWhat it does
Ctrl+Shift+FSearch in Tracks — jumps from any playlist/crate to the Tracks view and puts the cursor in the search box (last Tracks search is selected, so typing replaces it). Plain Ctrl+F still searches in the current view.CP112
p / Shift+pPreview the selected track / start-stop the preview (stock keys). Since CP87 they take the track from whichever list has the focus — also the side panes.CP87
Left / RightWhile the preview deck plays: skip 10 % back / forward. Right on a different track loads that one into the preview and plays it. When nothing previews, they are normal cursor keys.CP85, CP86
Ctrl+Shift+PToggle the beat click in the preview deck (beatgrid check).CP88
Ctrl+LStart / end a live session (crowd rating log). Live Broadcasting no longer uses Ctrl+L.CP113d
Ctrl++ / Ctrl+- / Ctrl+0Crowd rating for the loudest playing deck: worked well / didn't work / neutral (numpad keys work too). Only while a live session runs.CP113
Ctrl+ZUndo loop / cue change on the deck that changed last: loop, hotcues (set, moved, deleted – label and colour come back) and intro/outro markers; press again to walk further back. In a text field Ctrl+Z stays normal text undo.CP115, CP129
F2 / DelRename / remove the selected smart playlist or playlist folder in the sidebar.CP43, CP68
Mouse on the BPM numberLeft click = tap tempo (as stock). Right click = type a BPM, Enter sets the rate so the track plays at that tempo; Esc or clicking elsewhere cancels. Mouse wheel does nothing (no accidents).CP55, CP56

All Ctrl shortcuts above are also in the Options menu, and can be remapped in mixxx.cfg under [KeyboardShortcuts] (OptionsMenu_LiveSession, OptionsMenu_CrowdRatePlus/Minus/Neutral, OptionsMenu_LoopUndo).

Library & search

  • Search in Tracks: Ctrl+Shift+F — see above. CP112
  • Tag completion in the search box. Type the start of one of your ! tags (e.g. last) and the rest is suggested inline (LastSong!); Right accepts, typing on replaces it, Backspace drops it. The tag list is search_tags.txt in the settings folder (one tag per line, # = comment; first match in the file wins, so the order sets the priority). Read when the skin loads. CP111
  • Stem search mode. Button right of the search box cycles ALL → STEMS only → NO STEMS; also in the skin settings (wrench) → Library → “Search shows”. Only narrows typed searches — browsing a playlist without search text is never filtered. Works in every list (Tracks, playlists, crates, Similar). CP114
  • Track # searchable globally. The Track # column (where your chord tokens live) is part of the plain free-text search, sorts as text and is left-aligned. “Search related Tracks → Track Number” searches its value. CP54, CP57, CP58
  • Stem tracks have a violet row tint in every track list (unless the track has its own colour). Colour/opacity in andys_stem_colors.ini. CP6, CP7
  • “Add to Playlist” shows 20 playlists plus “Show All Playlists (N more)…” instead of a full-screen menu. CP96
  • Library controls act on the focused list. Load buttons, p, Auto DJ add, rating and colour keys (and mapped controller buttons) use the list you clicked into last — main library or a side pane. CP87
  • Fix: the library no longer jumps back to the selected track ~5 s after a search that ended with a space. CP110

Playlists & sidebar

  • Sort order: playlists are sorted by leading underscores first (_ to _____ = pin level 1–5, more underscores = higher), then newest first. CP2
  • Folders: name a playlist Folder/Name and it appears inside an expandable Folder (one level). Right-click a playlist → Move to Folder (existing folder, New Folder…, Remove from Folder). Right-click a folder → Rename Folder (or F2). Open/closed state is remembered. CP40, CP43
  • Only 10 rows + “More… (N)”: the Playlists node shows the top 10 entries; click More for all. Collapsing Playlists folds it back to 10. A selected / just-created playlist is never hidden. CP106
  • Smart playlists (sidebar → Smart Playlists): saved searches that update with the library. Right-click the root → New Smart Playlist → name + search query (full search syntax: artist:, bpm:120-125, -, |, …). Right-click one → Edit Search Query / Rename / Remove. The search bar narrows inside it. Re-evaluated when you click it, never during a set. Stored in andys_smart_playlists.ini, not in the database. CP68
  • Right-click a playlist → Mark all tracks played / unplayed.
  • Right-click a playlist → Replace Tracks With Stem Versions / Replace Stem Tracks With Originals — swaps the whole playlist in place; tracks without a counterpart stay. CP46
  • Right-click a playlist → Open in side pane (see side panes).

Find Similar

  • Right-click a track → Find Similar → the Similar sidebar item lists every track with similarity ≥ 0.9 (at least the 10 closest), with a Rank column (the seed track on top as rank 0) and a Similarity column. The search bar filters inside the results. CP95, CP102
  • On a stem track it uses the original's sound vector. “(no similarity data)” = the track is not in the index yet. CP99
  • Needs similarity.sqlite at the library root (built by Clawy's exporter); nothing is written to the Mixxx database. Threshold: [Similarity] min_score in mixxx.cfg (default 0.9).

Stems

Look

  • RGB stem waveforms: each stem is coloured by frequency content (like the normal RGB waveform), the outline keeps the stem colour. CP4
  • Fixed stem colours across the library: drums amber, bass red, other cyan, vocals pink — editable live in andys_stem_colors.ini (applies on next track load). CP3, CP7
  • One lane per stem: Preferences → Waveforms → “Show each stem in a separate lane” (live toggle). Lanes keep a fixed order, the stem strip knobs line up with the lanes. CP17, CP19, CP47

Stem ↔ original

  • Metadata → Import From Original Track (on stem tracks): copies hot cues, loops, beat grid, BPM, key and metadata from the normal version. Alignment is measured from the audio, so cues land right even with a codec delay. Warns before overwriting your own cues. CP45, CP51, CP53, CP93
  • Deck track menu → Swap with Stem / Original Track (deck playing): loads the counterpart into a free deck with its fader down, at the exact same musical position, same tempo/pitch, playing — you fade over yourself. The playing deck is never touched. CP97, CP97b, CP100
  • Deck track menu → Replace with Stem / Original Track (deck stopped): swaps the track in the same deck at the same position; tempo, pitch, EQ and gain stay. CP120
  • Track menu in a playlist / Auto DJ → Replace with Stem Version / Replace with Original (mixed selection: “Swap Stem and Original Versions”): swaps just the selected rows in place. Not in history playlists. CP116
  • Whole playlist: see Playlists. Marking one version played can mark the other too: see Tagging.

Performance

  • Parallel Stems (Preferences → Sound Hardware): time-stretches the 4 stems on several CPU cores instead of one — helps with keylock on stem decks. CP39
  • Stem tracks no longer re-analyse their waveform on every load. CP60, CP101

Preview deck (pre-listening)

  • p previews the selected track (stock) — now from the focused list, side panes included. CP87
  • Left/Right skip ±10 % while it plays; Right on another track hands the preview over to it. Step size: [PreviewDeck1],seek_percent_size. CP85, CP86
  • Beatgrid check click: a click on every beat while the preview plays — if clicks and drums drift apart, the grid/BPM is wrong. Preferences → Beat Detection → “Beatgrid Check” (+ click volume), or Ctrl+Shift+P. Never on the main decks. CP88
  • Where the preview deck sits (AndyVideo skin settings): Sidebar / Above Library / Below Library / Above Pane / Below Pane, plus Preview Auto-Hide (only visible while previewing). CP74

Decks, tempo & key

  • Type a BPM: right-click the deck's BPM number, type, Enter. Left click still taps tempo. CP55, CP56
  • Zouk / Fusion switch at the top of the skin settings (= Preferences → Decks → Zouk mode). Zouk = every loaded track is automatically key-matched to the playing deck (like pressing MATCH), and the key turns red when two playing decks clash (Camelot distance > 2). CP35, CP36, CP118, CP121
  • Key offset in the key label: 11m (4m +1) = playing in 11m now, track is 4m, moved +1 semitone. Turns orange with a decimal (+1.3) when between semitones. Hover it: original key + what reset does; hover the key ↑/↓ buttons: which key you'd land on. Toggle: skin settings → Decks → “Key Offset (semitones)”. CP72, CP73, CP75, CP103
  • Controller mode frame: when you change the ±-pad mode on the APC Mini, a yellow frame shows for ~2 s around the deck controls it now drives (jump, loop move, loop size, jump size, tempo, key; orange for key fine). CP104
  • Crowd rating tint: during a live session a deck is tinted green/red/yellow with the latest rating of its track. CP113
  • Undo loop / cue change: Ctrl+Z or Options → Undo Loop / Cue Change (controller: [LoopUndo],undo). Covers the loop, the loaded track's hotcues and saved loops (set, moved, deleted, label/colour) and its intro/outro start/end markers – not the main cue. Changes on one deck within 300 ms = one step. A toast shows what was undone (e.g. “Deck 2: outro marker change undone”). Loading a track drops that deck's history. CP115, CP129
  • The asymmetric (−32/+8 %) and exponential pitch faders were tried and removed again (CP28–CP30).

Loading tracks

  • Loading from the library (load button / controller / load to next deck) alternates over the free decks: 1, 2, 1, 2… A playing deck is skipped. CP41, CP94
  • If every visible deck is playing, the track replaces a muted one (fader down, EQs/stems all down, muted, or off the main mix) — never a deck that is merely quiet. No muted deck → nothing loads (it never spills into hidden decks 3/4). CP94

Headphones / cue

  • Auto Headphones (Preferences → Mixer → “Auto Headphones: cue silent decks automatically”, or [Master],auto_headphones): the quietest loaded deck is put on the headphones automatically. Pressing a headphone button yourself wins until you press again; while the preview deck plays, nothing is auto-cued. CP89–CP89d
  • Cue before EQ ([Master],headphone_pre_eq, APC pad row 8 #3): hear a deck in the headphones without its EQ (killed bands audible). Cue without filter ([Master],headphone_pre_filter, pad #4). Per session, not saved. CP79–CP82, CP109
  • Stem cue ([Master],stem_cue_1..4, APC pads row 8 #5–8 in stem mode while deck 4 is empty): e.g. hear all vocal stems raw in the headphones even with the vocal fader down; the other stems are heard as the crowd hears them. Only affects decks on headphones. CP107, CP108
  • Hotcue right-click popup now opens on the correct monitor (external screens). CP92

Waveforms

  • Zoom out to 50 (was 10) — ~1½ minutes of look-ahead. When beat lines get too dense they thin to every 4th, then every 16th, then disappear. On the APC Mini: SHIFT + fader 9. CP105
  • Killed EQ ghost: a killed band leaves a dimmed grey trace instead of a blank gap. Preferences → Waveforms → “Show killed EQ bands as a dimmed ghost”. CP84
  • Fix: two decks with different sample rates now scroll at the same speed after tempo-matching. CP83
  • Stem waveform features: see Stems.

Skins & layout

AndyVideo skin

  • Video-first layout: decks + mixer + spectrum analyzer on the left, a presenter column with your playlist pane on the right (draggable width). The mixer/spectrum column stays centred on resize (auto_center in andys_layout.ini). No private info lines on camera. CP9–CP14
  • Classic Layout (skin settings → Layout): LateNight-style decks and library, playlist pane as a strip below the library. In classic: AutoDJ At Bottom swaps Auto DJ and the playlist pane. CP48, CP65
  • Free splitter resizing, decks keep their height (library gives way), constant sidebar width, splitter handle can't vanish under the waveform. CP70, CP74, CP77, CP78
  • Collapsible skin settings: every section of the wrench panel folds (click the header or the ▾/▸ arrow); remembered. CP117

Side panes (both skins)

  • Second playlist pane: right-click a playlist → Open in side pane. Drag tracks between it and the library, own columns and sort. ⏏ button unloads it. Select 2+ tracks → total duration and count in the header. CP8, CP11, CP31, CP33
  • Spoiler-free mode (– / 👁 button in the pane header): shows only the played songs plus the next one — nothing to spoil on camera. CP24, CP32
  • Auto DJ side pane: a full Auto DJ next to the library, so Auto DJ and a playlist are open at the same time; can be shrunk to zero. CP8b, CP27

Everywhere

  • “ANDY'S MIXXX” logo, splash and window title. Installs side by side with official Mixxx (“Andys Mixxx”); both share the settings folder and database. CP5, CP11
  • Latency meter (toolbar) shows the peak per callback, not the average. Border: yellow/amber = close to the limit, red = real buffer underflow. CP39
  • Minimum widget sizes / tighter library rows: andys_layout.ini (restart needed). CP12

Spectrum analyzer

  • Retro LED spectrum of the main output (AndyVideo, presenter and classic layout). On/off: skin settings → Spectrum Analyzer — off costs zero CPU. CP10, CP37, CP38, CP49
  • Feel (fall speed, gravity, peak hold, attack, frame rate) and band count (default 32) in andys_spectrum.ini. Motion values reload live when Spectrum Live Reload is on (skin settings); the band count needs a restart. CP12–CP13c, CP18, CP62, CP63

Live gigs

  • Live session / crowd rating: Ctrl+L or Options → Start Live DJing… → event name + style (Zouk/Fusion preselected from the switch). While it runs:
    • every track audible for ≥ 30 s is logged as played;
    • Ctrl++ / Ctrl+- / Ctrl+0 rate the loudest deck (toast + deck tint), or right-click a track → Crowd Rating;
    • log file: live_sessions/yyMMdd_<event>.jsonl in the settings folder. Restart mid-gig → Mixxx offers to continue the session.
    Nothing is written to the database or the star rating. CP113–CP113d
  • Practice mode (Preferences → Library → Session History): browsing/cueing/tagging doesn't count — no play count, last played or history entry. Turn it off for real gigs. CP91
  • Recording auto-name: just record as usual. When you stop, the file is saved first, then a recording with 1–10 tracks is renamed to your convention: 2026-10-25_22h10m00s_Zouk_X__TrackOne_TrackTwo.mp3 (Fusion when the Zouk/Fusion switch is on Fusion; X = not rated yet, so you swap in S/A/B/C/D and add a set title by hand). A track counts if it was audible on the main mix (playing, fader up, not muted, crossfader side open) for ≥ 30 s in total, on any deck. If all titles don't fit in about 200 characters, the name stops at the last whole title that fits. Titles are CamelCase with no accents, and feat./(…)/[…]/“- … Remix” parts are dropped. Longer recordings, split files and failed renames keep the time-only name. The .cue file is renamed too. CP124, CP127, CP128
  • Loop / hotcue / intro-outro undo: Ctrl+Z. CP115, CP129
  • Controller lights watchdog: if Windows stops accepting messages to the controller (lights freeze, buttons still work — happened live on 2026-10-25), Mixxx shows a “Controller lights offline” warning, retries every 2 s and, once the connection is back, redraws every light to the current state (“Controller lights back”). If they stay frozen: unplug the controller and plug it back in into the same port; the retry should pick it up, otherwise Preferences → Controllers → Rescan. A dead connection can no longer hang the rescan. CP125
  • Gig safety: don't press “Rescan controllers” mid-set (drops all controllers for a moment).

Tagging & played status

  • Metadata → Rate / Tag for the Files… (track menu, also from a deck, works on a selection): tier rating for today (S/A/B/C/D), hand energy (00000 ambient … 99999 party), tags to add / remove — typing 2+ letters suggests your tags from search_tags.txt (Up/Down + Enter picks one, , is added for the next). Nothing is written to the file or the DB yet — one line per track goes to track_edits/track_edits.jsonl in the settings folder, which Clawy applies to the files later (PhoneDJ format). CP119, CP123
  • Track menu → Mark as Played / Mark as Unplayed (any selection; play count untouched). CP34
  • Mark related tracks played (Preferences → Auto DJ): marking a track played also marks its stem/original counterpart and other versions of the same song (remixes, edits, typos), so Auto DJ skips them. Optionally counts them as really played. CP66

APC Mini controller (myController.js, v40)

The mapping is installed separately (copy myController.js + the .midi.xml into the controllers folder, then disable/enable it in Preferences → Controllers). Short version:

  • Grid: per deck a transport row above its 8 hotcues (deck 1 on top). Transport: play · cue · rate −/+ · reloop · beatloop · − · +. Play pad: yellow = stopped, red = playing & audible, green = playing but silent; on a live deck press play twice to stop.
  • Hotcues: empty = set, yellow = jump, green = loop cue. On an audible deck the first press arms (red), the second jumps. SHIFT + pad = delete (grid turns red).
  • ± pad modes (green scene buttons, right column): 1 beat jump · 2 move loop · 3 loop size · 4 jump size · 5 tempo · 7 key ±1 semitone · 8 key ±10 cents. The screen shows a yellow frame around the matching controls.
  • Deck pair: SHIFT + scene buttons 5–8 selects deck 1–4; the faders work on the pair 1+2 or 3+4.
  • Faders, EQ mode: 1–3 low/mid/high EQ crossfade between the pair · 4 filter crossfade · 5 deck A volume · 6/7 deck A/B rate · 8 deck B volume · 9 headphone mix (SHIFT = waveform zoom).
  • Stem mode (SHIFT + rightmost track button): faders 5–8 crossfade drums / bass / other / vocals between the pair; stem mix survives track loads.
  • Track buttons: tap = reset the fader below; hold = subtract-only (fader can only make things quieter — take both sides out). EQ mode right half: PFL A · sync A · sync B · PFL B. Filter button blinks while a filter is off-centre.
  • Row 8 cue pads (deck 4 empty): pad 3 cue before EQ · pad 4 cue without filter · pads 5–8 stem cue (stem mode).

Full details: mixxx-build/controller/FEATURES.md + CHANGELOG.md (ask Clawy).
